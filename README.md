# 🏪 GRABIT: Unified Utility & Food Ecosystem

A Streamlit prototype app for managing a college canteen/store.  
Built as a **CSE 3rd Year Mini Project Expo Prototype**.

## 🚀 Features
- Role-based login system:
  - **Student/College User**
    - Browse catalog (Food & Stationary)
    - Place orders with auto-generated tokens
    - Send custom item requests
    - Track order status
  - **Canteen Manager**
    - View and process active orders
    - Update inventory (price, stock, delete items)
    - Handle student requests and add them to catalog

## 🛠️ Tech Stack
- Python
- Streamlit

## 📂 Project Structure
- `app.py` → Main Streamlit app
- `requirements.txt` → Dependencies

## ▶️ Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
